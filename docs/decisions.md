# 設計判断の記録

## 印刷専用ページとして独立させる(2026-10-31)

診察後に獣医師が口述 → ChatGPTが「カルテ(SOAP)」と「飼い主さんへのまとめ」の2つを出力 →
カルテはnyuta-karte-logへ、まとめはこのページに貼って印刷する、という流れの印刷部分を担う。
ChatGPTの画面から直接印刷すると会話全体が出てしまうため、渡せる紙の形にする場所として作った。

**理由**: 診療中は電子カルテ・ChatGPT・karte-logをすべてiPadのブラウザで使っているため、
同じブラウザのタブで完結させると切り替えがない。将来karte-logに組み込む場合も、この印刷部分を部品として使える。

## 保存・送信をしない

貼り付けた文章はメモリ上でのみ扱い、localStorage等にも残さない。ページを閉じると消える。

**理由**: 飼い主・動物の情報を含む。記録はkarte-log側に残るので、このページで持つ必要がない。

## 【要確認】が残っていると印刷できない

ChatGPTの指示書で、薬の量・回数・日数などが口述から欠けている部分は【要確認】と書かせている。
これが1つでも残っている間は印刷ボタンを押せないようにした。

**理由**: 薬の情報が欠けた紙が飼い主に渡るのを防ぐ。渡す前に受付が会計明細・薬袋と【お薬】欄を見比べる運用と二重で守る。

## 貼り付けた文章の読み取り規則

- 「本日の診察のまとめ」→ 題名、「(〇〇の飼い主様へ)」→ 宛名
- 【見出し】だけの行 → 見出し(【要確認】は除く)
- ``` の行、「出力1：」「出力2：」の行、末尾の「にゅうた動物病院」は取り除く(紙の上下に病院名を入れるため)

## アイコン(2026-10-31)

封筒に、緑の肉球の封蝋を押した絵柄。ブラウザのタブ・ホーム画面に置いた時に「お手紙」と一目で分かるようにした。
icon.svg(タブ用)と、apple-touch-icon.png(iPadのホーム画面用、180px)、icon-192/512.png(manifest.json用)を置いている。

## 「検査結果のご説明」も同じページで印刷する(2026-10-31)

診察の途中で検査結果を説明するための紙(ChatGPTの別プロジェクトで作る)も、このページで印刷する。
1行目が「本日の診察のまとめ」または「検査結果のご説明」なら、その文字を紙の題名にする。

## フッターにAIの使用と確認の一文を固定で入れる(2026-11-04)

院長「この書面がAIの要約に則っているので、間違うことがありますみたいな一文を入れた方が良いのでは」。
相談の結果、「間違うことがあります」とは書かない(責任は病院に残るので言い訳に見え、紙全体の信頼を下げる)。
AIを使ったことは隠さずに書き、実際の安全策(獣医師の確認・薬袋の表示が優先)をそのまま書く。院長のOKで次の文面に決定:
「この書面は、診察でお話しした内容をAIの文章作成支援を使ってまとめ、獣医師が確認したものです。お薬の量や回数は、お薬の袋の表示を優先してください。分からない点があれば、お気軽にお問い合わせください。」
「本日の診察のまとめ」「検査結果のご説明」のどちらにも同じ文が付く。もとの「ご不明な点やご心配なことがあれば…」はこの文の最後に含めた。
